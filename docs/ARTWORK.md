# Pixel Studio artwork

`extension/assets/approved-reference.webp` is a lossless WebP encoding of the approved concept image. The three theme cards use CSS background viewports into its Night, Forest, and Sakura thumbnails, rather than replacing those pictures with procedural approximations. Selection borders and check badges are real interactive CSS.

`night.webp`, `forest.webp`, and `sakura.webp` are full scene assets generated in the approved composition and subsequently edited into a coarse 16-bit pixel art style at the user's request. Their pixels are preserved by lossless WebP encoding. The empty sky allows stars, clouds, and the moon to remain separately controlled overlays.

These art files ship with the extension. The userscript manager downloads the same files as declared resources during installation/update. User uploaded wallpapers never become repository files.
